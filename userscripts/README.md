# userChrome.js 用スクリプト

[English](README.en.md)

- 入れ方: 使うスクリプトをプロファイルの `chrome\` フォルダ(`utils\` があるところ)に入れて再起動。ローダーが必要
- Floorp 12.21 で使用中

## NavWheelButton.uc.js

戻る・進む・更新・中止を 1 つのボタンにまとめる。

- 戻るボタンのあった場所に入る
- ホイールを回す → 履歴が出る。止めると、そのページへ移動
- クリック → 更新(読み込み中は中止)
- 右クリック → 履歴の一覧。右上の歯車で設定

## UrlbarIconDrawer.uc.js

アドレスバー右端のアイコンを「<」ボタンにしまう。

- アイコンを右クリック →「アイコンを非表示」
- 「<」を押すと、しまったアイコンが出てくる
- ドラッグで並べ替え

## UrlbarExtensionButtons.uc.js

拡張機能のボタンをアドレスバーの中に置く。

- ボタンを右クリック →「アドレスバーに置く」/「アドレスバーから外す」

## UrlbarUpLevel.uc.js

URL の上の階層へ移動する。

- Ctrl を押しながら URL の区切りをクリック → そこまで移動
- アドレスバーの ↑ ボタン → 上の階層の一覧

## SearchWordButtons.uc.js

検索ボックスの単語でページ内を検索・強調する。

- ツールバーに検索ボックスが必要
- 入力欄の右の「A」ボタンで強調のオン・オフ
- 検索ボックスから離れると単語ごとのボタンになる。クリックで次の場所、Shift+クリックで前の場所

## ContextMenuEditor.uc.js

ページとタブの右クリックメニューを編集する。

- メニューのいちばん下の短い横線 → 編集画面
- 隠す・並べ替え・サブメニューにまとめる・区切りを足す
- 「完了」で保存、「元に戻す」で元の並び

## DownloadManagerPlus.uc.js

閲覧履歴を消しても残るダウンロードの一覧。

- ダウンロードボタンの隣にボタンが増える
- パネル: 一時停止・再開・中止・やり直し・フォルダを開く。× で一覧から消す(ファイルは残る)
- ウィンドウのアイコン → 専用ウィンドウ(検索・並べ替え・まとめて削除)
- 「ファイルを削除」はごみ箱に入らない

## CookieManager.uc.js

いま開いているサイトの cookie を見る・編集・削除・書き出し。

- アドレスバーのクッキーのアイコン → パネル
- 書き出した cookie はログイン情報そのもの。人に渡さない

## TabGroupsWindow.uc.js

[Tab Groups](https://github.com/117649/Tab-Groups) のグループを別のウィンドウで開く。

- Tab Groups 2.2.0 以降が必要。`about:config` で `floorp.workspaces.enabled` を `false`
- タブを右クリック →「このグループを新しいウィンドウで開く」
- そのウィンドウを閉じると、グループが元のウィンドウの元の位置に戻る

## TabGroupsHelptextFix.uc.js

- Tab Groups の設定画面で、1 回目のクリックが効かないことがあるのを直す

## TabMixMultiRow.uc.js

Tab Mix Plus の複数行タブを使いやすくする。

- タブのスクロールボタンの上でホイール → 1 行ずつ動く
- 最後の行の空いているところをダブルクリック → 新しいタブ
- 古い `TabScrollButtons.uc.js` があれば消す

## rebuild_userChrome.uc.js

スクリプトの一覧と、オン・オフの切り替え。

- `about:userchromejs` を開く(≡ メニューの「userChrome.js スクリプト」からも)
- 切り替えは再起動で反映
- ファイル名は変えない
